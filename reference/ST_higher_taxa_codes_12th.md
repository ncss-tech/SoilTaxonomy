# Letter Code Lookup Table for Position of Taxa within the Keys to Soil Taxonomy (12th Edition)

A lookup table mapping unique taxonomic Order, Suborder, Great Group and
Subgroups to letter codes that denote their logical position within the
Keys.

## Usage

``` r
data(ST_higher_taxa_codes_12th)
```

## Format

An object of class `data.frame` with 3082 rows and 2 columns.

## Details

The lookup table has been corrected to reflect errata that were posted
after the print publication of the 12th Edition Keys, as well as typos
in the Spanish language edition.
