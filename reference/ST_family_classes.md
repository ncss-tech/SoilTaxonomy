# Family-level Classes for Soil Taxonomy

A database of family-level class names for Soil Taxonomy.

## Usage

``` r
data(ST_family_classes)
```

## Format

An object of class `data.frame` with 194 rows and 8 columns.

## References

Soil Survey Staff. 2014. Keys to Soil Taxonomy, 12th ed. USDA-Natural
Resources Conservation Service, Washington, DC.
<https://www.nrcs.usda.gov/resources/guides-and-instructions/keys-to-soil-taxonomy>
