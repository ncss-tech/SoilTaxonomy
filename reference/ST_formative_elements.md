# Formative Elements used by Soil Taxonomy

A database of formative elements used by the first 4 levels of US Soil
Taxonomy hierarchy (soil order, suborder, greatgroup, subgroup).

## Usage

``` r
data(ST_formative_elements)
```

## Format

An object of class `list` of length 4.

## References

S. W. Buol and R. C. Graham and P. A. McDaniel and R. J. Southard. Soil
Genesis and Classification, 5th edition. Iowa State Press, 2003.
